# Personal Portfolio

A clean, responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript.

## Features

- **Responsive design** — works on all screen sizes
- **Smooth scrolling** navigation with active section highlighting
- **Sections**: Hero, About, Skills, Projects, Contact
- **Contact form** with client-side validation
- **Scroll-reveal** animations
- No build tools or frameworks required — open `index.html` directly in a browser

## Project Structure

```
personal-portfolio/
├── index.html   # Main page structure
├── style.css    # All styles (dark theme, responsive)
├── script.js    # Navigation, form validation, animations
└── README.md
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Aartikkk/personal-portfolio.git
   cd personal-portfolio
   ```
2. Open `index.html` in your browser — no installation needed.

## Customisation

- Replace **"Your Name"** in `index.html` with your own name.
- Update the **About**, **Skills**, and **Projects** sections with your own content.
- Set the social links in the footer to your GitHub, LinkedIn, and Twitter profiles.
- Swap the avatar placeholder (`.avatar-placeholder`) with your own photo `<img>` tag.
- Connect the contact form to a backend service or a form provider (e.g. Formspree).
